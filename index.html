Qanday ishlaymiz

Hamma bir xil yo'l bilan ishlaydi, shuning uchun kodimiz aralashib ketmaydi.

  1. Loyihani oling

    Sayt nusxasini kompyuteringizga yuklab oling.

    git clone

  2. O'z tarmog'ingizni oching

    Guruhingiz uchun alohida branch yarating.

    git checkout -b guruh-nomi

  3. Sahifani yozing

    HTML va CSS bilan sahifangizni tayyorlang va saqlang.

    git commit -m "Sahifa tayyor"

  4. GitHub'ga yuboring

    O'zgarishlarni yuboring va jamoa ko'rib chiqsin.

    git push origin guruh-nomi
